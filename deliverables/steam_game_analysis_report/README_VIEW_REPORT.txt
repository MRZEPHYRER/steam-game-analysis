Steam Game Market & Player Review Analytics
============================================

Open the HTML file in any modern browser. The report is a single-file,
offline-capable export: figures, CSS, JavaScript, and MathML formulas are
embedded in the HTML. No project directory, R, Quarto, Python, MySQL, or
database credentials are required to view it.

This sharing package contains presentation outputs only. It does not contain
the project database, raw data, .env files, credentials, caches, or tests.
